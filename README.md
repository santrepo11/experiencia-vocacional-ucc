# Experiencia Vocacional UCC

Aplicación web moderna para visualizar el futuro profesional de aspirantes a la Universidad Cooperativa de Colombia.

## Tecnologías

- React 18
- TypeScript
- Vite
- Tailwind CSS
- React Router
- Zustand
- TanStack React Query
- Axios
- Framer Motion
- Recharts

## Requisitos

- Node.js 18+
- npm

## Instalación

```bash
npm install
npm run dev
```

La app se abre en http://localhost:5173

## Funcionalidades

- Landing con acceso y autenticación mock
- Inicio del recorrido vocacional
- Registro con validaciones de datos y carga de foto
- Proceso de generación con pantalla de progreso
- Resultado con vista final, descarga y compartir por WhatsApp
- Dashboard administrativo con métricas y gráficos
